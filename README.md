## 🚀 Projet phare

### 🦅 Lecteur API eBird

Application web **open source** pour explorer les observations d'oiseaux **en temps réel** grâce à l'API publique eBird. Interface moderne avec carte interactive, recherche par espèce, export de données et mode sombre.

<table>
<tr>
<td width="50%">

**✨ Fonctionnalités**
- 🗺️ Carte interactive (3 fonds : clair, satellite, topographique)
- 🔍 Recherche par espèce et par lieu
- 📍 Sélection de zone (respect de la limite 50 km)
- 📥 Export CSV / JSON / TXT
- 🌙 Thème clair / sombre
- 📱 Interface responsive (mobile & desktop)

</td>
<td width="50%">

**🛠️ Stack technique**
- JavaScript vanilla
- HTML5 / CSS3
- Leaflet (cartographie)
- API eBird 2.0
- hCaptcha (sécurité)
- Vercel (hébergement)

</td>
</tr>
</table>
